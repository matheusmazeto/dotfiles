# Design

- Prefer clear hierarchy, generous spacing, and restrained visual decoration.
- Avoid unnecessary gradients, excessive shadows, and ornamental UI that does not improve comprehension.
- Design loading, error, empty, hover, focus, and responsive states deliberately.
- Keep typography, color, spacing, and interaction patterns consistent across the interface.
- Favor accessible contrast, visible focus states, semantic structure, and usable keyboard navigation.
